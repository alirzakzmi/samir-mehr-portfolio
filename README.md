## 🔗 دموی زنده

[مشاهده سایت](https://alirzakzmi.github.io/samir-mehr-portfolio/)

## 🔐 ورود به پنل مدیریت

برای مشاهده پنل مدیریت (نسخه دمو) روی لینک زیر کلیک کنید:
[ورود به پنل ادمین](https://alirzakzmi.github.io/samir-mehr-portfolio/admin/login.html)

**اطلاعات ورود تستی:**
- **ایمیل:** هر ایمیل معتبری (مثل `admin@example.com`)
- **رمز عبور:** حداقل ۸ کاراکتر
- 
## 🎨 تکنولوژی‌ها

- HTML5
- CSS3 خالص
- Vanilla JavaScript
- فونت‌های پیش‌فرض سیستم (بدون لینک خارجی)
- RTL کامل

## ✨ صفحات

| صفحه | مسیر |
|---|---|
| صفحه اصلی | `index.html` |
| همه محصولات | `products.html` |
| جزئیات محصول | `product.html` |
| صفحه دسته‌بندی | `category.html` |
| **پنل مدیریت** | `admin/login.html` |

## 📁 ساختار

```
assets/
├── css/style.css     ← تمام استایل‌ها
├── js/main.js        ← هدر، فوتر، منو، اسلایدر، صفحه دسته‌بندی، فرم ورود
├── js/admin.js       ← سایدبار، زیرمنوها، پیش‌نمایش تصویر، Slug
└── images/
admin/                ← صفحات پنل مدیریت
```
